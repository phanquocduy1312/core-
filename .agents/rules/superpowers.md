# Superpowers Rules & Guidelines

All agents working in this workspace must strictly follow the Superpowers principles:

- **TDD First:** Write failing tests first before writing production code.
- **Root Cause Debugging:** Never patch symptoms without full root cause analysis.
- **Evidence Before Claims:** Always verify with execution commands before claiming task completion.
- **Brainstorming & Planning Gates:** Get user approval on designs and specs before implementing.
- **Task Right-Sizing:** Break plans into 2-5 minute bite-sized tasks.
